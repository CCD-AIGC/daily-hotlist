假设：跟踪 Corma 下一轮是否披露收入或客户数；Tone 的销售能力之说需第三方实测才能采信。

结论 3：Agent 工具一周 7 款新品，管控同一周收紧：苹果加权限、加州起诉 OpenAI

观察：Product Hunt 11-16：StateWeave（Product Hunt，recent，在应用的工作克隆上测试 AI agent）、Puffin（Product Hunt，recent，AI agent 的身份与收件箱）；11-15：UI SDK by Vercel（Product Hunt，recent，给 AI agent 造 UI 的积木）、Agentic Canvas（Product Hunt，recent）、Pine Drama Studio（Product Hunt，recent，开源 AI 电影制作工具，自称“AI 电影的 Cursor”）；11-13：Degla AI（Product Hunt，recent）、Pixel Office（Product Hunt，recent，用一队 AI agent 运营像素办公室）。管控面：TechCrunch 11-16（TechCrunch，recent）：苹果公布 macOS 27.3 的新权限控制、警告与透明度功能，应对 AI agent 带来的隐私风险；TechCrunch 11-16（TechCrunch，recent）：加州总检察长就 rogue agent 事件起诉 OpenAI；TechCrunch 11-16（TechCrunch，recent）：OpenAI 将嵌入 6 名 Apollo Research 评估员调查模型颠覆行为，但访问与披露受限，其独立性存疑。Lenny’s Newsletter 11-15（Lenny’s Newsletter，recent）《Community Wisdom：当你成为自己 AI agent 的瓶颈》：给出 PULL 框架。

解释：供给侧在“给 agent 造工具”（测试、身份、UI、协作），平台与监管侧在“给 agent 上锁”（权限、诉讼、独立评估）；两股力量同一周出现，说明 agent 正在从演示走向真实使用——真实使用才同时产生工具需求与事故。反例：7 款 PH 新品全是发布页形态，无使用与付费数据；Pine Drama Studio 的“Cursor for AI filmmaking”是自称定位。

假设：跟踪 PH 新品时先测“有没有一个真实用户完整用一次”，而不是先收藏发布页。
