产业链结构 · 成本拆解 · 技术实现路径 · 合规边界
调研日期：2026-10-28 ｜ 触发源：《证券时报》2026-10-26 A2 版报道

核心结论（先给答案）

  1. 那篇微信文是转载，不是原创。原文为《证券时报》2026 年 10 月 26 日 A2 版《"探店"不"到店"！记者实测"AI探店"：花不到 10 元，视频出炉！有公司月流水达 800 万》。你给的链接是被几十个公众号二次分发的版本，信息量与原文完全一致——原文刻意没有点名工具，只描述为"一个 AI 视频生成工具的网页端入口"。
  2. 价格不是"技术便宜"，是"封装加价"。记者那条 12 秒 480P 视频花 9.6 元，折合 0.8 元/秒。而同期底层模型 API 的 720P 刊例价在 0.19–1.51 元/秒之间。也就是说：它用 480P 的画质，收了 720P 里偏贵的那档钱，加价率约 1.3–4 倍。便宜的是"省掉了人和设备"，不是"算力突然变廉价"。
  3. 0.18 元教程是引流品，不是商品。真实收费链条是「教程引流 → 积分充值（1 积分 = 1 元，最低 20 元）→ 299 元年度会员 → 持续算力消耗」。虚拟教程边际成本为零，所以能卖 0.1 元。
  4. "9.6 元"是最低配 + 一次成功的口径，不是交付成本。480P 在 2026 年已低于抖音竖屏可用标准（1080×1920）。按 15 秒 1080P + 平均抽卡 3–4 次 + 配音剪辑计算，一条真正可投放的成片实际成本约 20–60 元，仍远低于真人探店的数千元——这才是这门生意成立的原因。
  5. "月流水 800 万"是流水口径，结构性成立但数字存疑。按 300–800 元/条倒推，相当于每月 1 万–2.7 万条、即每天 330–890 条。这需要完整的矩阵账号 + 分发 + 投流体系，800 万很可能是"内容制作 + 代投放预算过账"的合计流水，而非纯制作收入。单一信源，无法二次核实
  6. 「不标注直接发」这条路在 2026 年已经被堵死。《人工智能生成合成内容标识办法》2025 年 9 月 1 日施行；2026 年 5 月中央网信办又推行 6 类必选标签，发布短视频必须从含"含有 AI 生成内容"在内的 6 类中选一项才能发布。合规做法只能用于"真实到店素材的增强"，不能用于虚构到店经历。

关于那个匿名工具：原文描述的操作界面——「上传门店/商品图 + 上传模特图 + 填门店信息 + 选比例/时长/分辨率 + 一键成片」——是 2026 年一类"聚合壳"产品的标准形态，不是某个自研模型。这类产品的共同特征是：自己不训练视频模型，而是把可灵 / 即梦 Seedance / 海螺 / Vidu / 通义万相的 API 封装成垂直场景表单，再按场景定价。公开可查的同类产品有 引力AI（"图片探店"模式）、shumi.quantv.com 等，均支持"1–8 张门店图 + 模特图 + 6/10/15 秒 + 多比例"这一套参数。报道中那款具体是哪一个，无法从公开信息确证，但其成本结构可通过底层 API 价格反推。

二、价格是怎么实现的：三层变现结构

第 1 层 · 引流
0.18 元
教程售价，边际成本≈0
第 2 层 · 沉淀
20–299 元
积分最低充值 / 年度会员
第 3 层 · 收割
0.8 元/秒
按次算力消耗，持续复购

这三层不是三个产品，是同一条漏斗。逻辑如下：

  • 教程卖 0.1–1 元：闲鱼虚拟商品，一份文档复制无限次，成本为零。它唯一的用途是把用户导流到特定工具网址——教程里附的是带渠道标识的入口，卖家靠后续充值分佣赚钱。
  • 积分 1 积分 = 1 元：这是关键设计。它把抽象的"算力"锚定成人民币，让用户对价格的感知变成"几块钱"，而绕开了与 API 实际价格的横向对比。最低充值 20 元是典型的低门槛首充设计。
  • 299 元年度会员：用"积分打折 + 进阶课程"锁定用户全年。对重度用户（代做商家）这是划算的，对轻度用户则是沉没成本。
看出来了吗：整套设计的利润来源不在"卖视频"，而在把模型的按量计费包装成预付积分制。教程是获客成本，积分是现金流，会员是留存。真正的成本项——底层 API 调用——被完全隐藏在"积分"这个计价单位后面。

结论：加价率约 1.3–4.2 倍。它卖的不是算力，是三样东西——场景封装（不用写提示词）、教程服务（不用自己摸索）、以及"不用理解模型差异"的认知成本减免。对商家而言这笔溢价是合理的；但"AI 让视频变便宜了"这个叙事，准确说法是AI 让视频的人力成本归零，同时把算力成本变成了新的收费项。

三、效果是怎么实现的：三条技术路线

报道里那句"原始图片中没有的行人、车辆和随风摇曳的树影"，是理解效果来源的关键——它说明画面不是对原图做插值，而是模型按物理规律"脑补"了运动和遮挡。当前 AI 探店实际存在三条路线，风险等级完全不同：

路线技术组合输入虚构程度风险
A. 图生视频
（报道所用）		图片 → 首尾帧/多图参考 → I2V 模型分镜 → 拼接门店实拍图 4–8 张 + 模特图中画面动效为模型生成，但场景主体来自真实素材
B. 数字人口播LLM 脚本 → TTS 配音 → 数字人对口型 → 门店图做背景/图文成片门店图 + 一段口播文案中高AI 演员口述"体验"，若未到店即虚构
C. 纯文生视频提示词 → T2V 直接生成（含排队人潮等场景）纯文字极高门店、菜品、人气全为虚构，法律风险最高

标准工作流（以报道中的路线 A 为例）

1素材准备：商家提供门店门头、环境、菜品特写 4–8 张（商家自有实拍，或大众点评/美团图片）
2模特图：上传 1 张"AI 演员"形象图，或选平台内置形象/无人物
3门店信息：店名、品类、卖点、团购信息 → 由 LLM 自动生成脚本与分镜（这是"不用写文案脚本"的真相）
4参数选择：模型 / 比例 9:16 / 时长 6–15 秒 / 分辨率 480P–1080P
5一键成片：平台按分镜逐段调用 I2V 接口 → 自动拼接 + 字幕 + BGM → 输出 MP4
6分发：矩阵账号批量发布 + 同城定向投流
"不用写文案脚本"是真的吗？是真的，但代价是同质化。LLM 生成的探店文案高度模板化（"宝藏咖啡店大公开！""这杯拿铁绝了！"），这也是为什么这类内容必须靠投流而非自然流量获得点赞——叶韦明副教授在报道中正是这样描述的："依靠投流获得点赞，建立在流量套利和虚假繁荣之上"。

我的判断（标注为推断，非事实）：数字本身需要打折看待。理由有三：
① 日均 330–890 条意味着一套成熟的工业化流水线，含获客、销售、账号矩阵养号、客服，这些成本未计入；
② "流水"不等于"营收"更不等于"利润"，若客户投放预算过账，流水会被显著放大；
③ 来源为"业内人士向记者透露"的单一匿名信源，无报表、无成本项、无可交叉验证的同行口径。
结构性结论成立：这是一个毛利率极高、门槛极低、靠规模套利的内容生意。但 800 万这个具体数字，不宜作为决策依据。

七、可行的落地姿势（不踩线的那种）

  1. 只做"增强"，不做"虚构"：以真实到店拍摄的 3–5 秒现场素材（含地理位置打卡、消费凭证）为底，用 AI 补足运镜、补光、空镜和字幕，文案可用 AI 润色。保留到店证据链是唯一安全的做法。
  2. 发布时主动标注：勾选平台"含有 AI 生成内容"标签 + 叠加"含 AI 生成内容"文字提示，不要指望隐式标识自动生效。
  3. 不用 AI 演员口述未发生的体验：数字人可以讲套餐、讲环境、讲营业时间；不能说"我吃了，很好吃"。
  4. 不用明星/网红脸、不克隆他人声音；模特图使用平台自有形象或有授权的素材。
  5. 优先走官方通道（巨量即创 / 腾讯妙思）：与投放系统原生衔接，标识合规由平台兜底，省掉自建合规环节。
