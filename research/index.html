收录规则给以后传调研的人和 agent 看

  • 文件放在 research/ 目录下，命名：YYYY-MM-DD-主题-来源.html，例如 2026-10-28-ai-tandian-workbuddy.html。
  • 原文 HTML 原样上传，不改内容；来源、日期、标题只写在栏目页和汇总入口的卡片上。
  • 每篇必须标明来源（WorkBuddy / Alder / 千问 / Claude Code / Codex 等），不同来源不混在同一篇里。
  • 新增一篇时，在本页对应来源下加一张卡，同时在汇总入口（hub.html）的“调研”栏目里加同一张卡，并登记到 research/research.json。
  • 时效数据（如模型价格）以原文标注的核查时间为准，使用前复核官方页面。
