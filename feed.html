这是什么订阅方式、多久更新、给谁用

  • 主源 feed.xml 每天更新：AI 商业情报（08:30）、GitHub 早期爆款雷达（08:30）、AI 内容雷达（12:00）三个主力系列混合，按发布时间倒序，近 30 天、最多 50 条。
  • 给 agent 用的 JSON API 在 api/v1/：latest.json（近 7 天，最多 100 条）、hot.json（当天评分最高前 10 条）、daily/ 按天拆分、search.json 全量索引、ai-news.json（最新一期标题 + 原文链接）。说明见 agent.md，接口定义见 openapi.json。
  • 这是静态文件托管，没有服务器：?limit= / ?window= / ?q= 不是服务器端参数，客户端拿到 JSON 后自己按 limit / window / category 过滤。建议 30 分钟刷一次，不要每分钟刷。
  • GitHub Pages 的静态文件没有精细的 Cache-Control / ETag 控制；feed.xml 的 Content-Type 可能是 application/xml 而不是 application/rss+xml，这是 GitHub Pages 的默认行为，订阅器一般都能正常解析。
  • 标题和摘要全部来自我们自己的筛选原文；AIHOT、LearnPrompt 等来源只学接口形态，不转载原文；ai-news 只给标题 + 原文链接，不写我们没核实的摘要。
