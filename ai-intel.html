05 每日一个 AI 赚钱案例：Perplexity：年化收入 run rate 超 10 亿美元，CEO Aravind Srinivas 11 月 16 日在 Semafor 活动上披露只写公开可核实的收入与价格，关键数据不公开就明说

产品卖给谁：AI 搜索的订阅用户与企业客户：把搜索与研究任务交给 Agent 的个人与团队；另有开发者通过 Orchestrator API 按量调用

收费方式：订阅制 Pro 与企业版加 API（Orchestrator API 11 月 9 日私测上线）；具体价目未在本窗口核实，不写数字

用户主要从哪里来：搜索产品自然流量 + Perplexity Computer 的 Agent 场景转化；增长 4 倍主要发生在 2026 年内

公开营收信号：年化收入 run rate 超 10 亿美元（CEO 11 月 16 日自述，非审计收入）；年初低于 2.5 亿美元，8 月超 7.5 亿美元（The Information 口径）；上轮估值 200 亿美元（2025 年 9 月）；IPO 申请可能提前至 2027 年第一季度（原计划 2028 年）

竞争优势：不训旗舰模型、只做聚合与 Agent 层，资本效率是核心卖点：CEO 称烧钱约为 Anthropic 的 1/5（自述，未审计），而年化收入已到同一量级区间；Perplexity Computer（2 月推出）是下半年增长主引擎，说明 Agent 功能比纯搜索更能拉动付费

可能成本结构：算力采购（调用他人模型）与获客是大头；不自研旗舰模型省掉了最贵的训练支出，但对上游模型定价没有议价权

可复制的经验：别在模型层竞争，要在 Agent 层赚钱：Perplexity Computer 把搜索变成“代办任务”（Automations、Teammates），订阅与 API 随之而来；用别人的模型、做自己的工作流，是小团队唯一可行的资本效率路线

不适合个人创业者的经验：搜索聚合本身做不了：需要大规模算力采购、品牌与分发渠道；个人冷启动的正确位置是垂直场景的搜索 Agent 或工作流（例如投研、电商选品），复用 Perplexity 这类聚合 API 而不是再造一个搜索引擎
