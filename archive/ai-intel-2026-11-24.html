05 每日一个 AI 赚钱案例：Anthropic 的“缓存税”：KV 缓存读取是模型公司的利润中心（新智元 11 月 23 日分析，数字为第三方估算、非官方披露）只写公开可核实的收入与价格，关键数据不公开就明说

产品卖给谁：用 Claude Code 等 Coding Agent 的开发者与企业：编程 Agent 反复重读上下文，产生大量 KV 缓存读取（Cache Reads）

收费方式：缓存读取按 Token 计费；Anthropic 11 月 9 日发布的 Fable 5.2 把缓存读取价降至每百万 Token 0.20 美元（Fable 5.1 为 0.25 美元，Fable 5 时代为 1 美元），两个多月降 80%；Anthropic 称仅降低缓存读取价格，就有望让复杂编程和 Agent 任务整体使用成本下降最多约 45%；输出 Token 单价往往比输入贵 5 倍

用户主要从哪里来：模拟与重放数据：Martin Alderson 模拟 6 万 Token 上下文、100 轮 Opus 5 会话，约 76% 的账单花在缓存读取上；Typesafe 联合创始人重放英伟达 Open-SWE-Traces 轨迹，输出 Token 仅占总账单 9% 到 18%；文章据此称编程 Agent 场景中超 90% 的 Token 消耗是反复读取历史记录——均为个人模拟/重放口径，未经官方确认

公开营收信号：无 Anthropic 官方毛利率或营收数字。SemiAnalysis 10 月估算：订阅仅贡献 Anthropic 约一成营收，却消耗四成以上推理算力；每月 200 美元的 Claude 顶级订阅最高可对应约 8000 美元/月的等效 API 用量（OpenAI 约 14000 美元/月），账面补贴约 40 到 70 倍；案例：Java Champion Vlad Mihalcea 称 Claude Pro 一年 200 美元用了 160 亿 Token，按 API 按量计费约需 10 万美元——以上均为第三方估算与个案，非 Anthropic 披露

竞争优势：定价结构本身就是护城河：Anthropic 的缓存读取 Token 不计入 API 输入速率限制；中途切换到便宜模型只为生成少量 Token，也需重写缓存、成本反而暴涨近 3 倍——锁定效应强；企业自部署可大幅降本（文章称 Uber 单 Token 成本降 50%、AT&T 降 56%、Pinterest 降 90%，Revolut 自购 56 块 B200）

可能成本结构：文章主张缓存读取的真实算力成本近乎为零，但未给出具体成本数字；KV 缓存加推测解码大幅压低真实推理成本，因此订阅制账面上的“倒贴”不等于真实亏损；但文章也承认重度订阅用户“多半还是要它倒贴”

可复制的经验：做 Agent 工具要先算清“缓存税”：长上下文反复读取是主要成本项，缓存命中率优化比模型选择更影响成本；缓存定价是模型公司调节利润的核心杠杆，Fable 两个多月降价 80% 说明这条线竞争正在加剧；给用户省缓存钱的工具（上下文压缩、缓存感知路由）本身就是一门生意

不适合个人创业者的经验：不适合直接复制——这是头部模型公司的定价权生意；个人可切入的是“帮用户省缓存钱”的工具层：上下文压缩、缓存命中优化、跨模型路由的缓存感知，不做模型本身
